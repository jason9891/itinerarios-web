PLATAFORMA ITINERARIOS WEB - VERSION 3
======================================
Base directa: VERSION 2 validada en operacion real.
No reconstruye versiones anteriores.

CAMBIOS VERSION 3
-----------------
1. GUARDAR PARCIAL
   - Nuevo boton en Seguimiento.
   - Consolida ediciones y cierres preparados hasta ese momento.
   - Registra fecha/hora, total de placas, cantidad revisada y listado exacto de placas revisadas.
   - Las placas REVISADA que continuan con OC abierta permanecen marcadas al reabrir Seguimiento.
   - No exige 100% para crear un reporte.

2. REPORTE PARCIAL NO FORZADO
   - Un corte PARCIAL valido habilita Crear Reporte.
   - Antes de descargar muestra aviso: X de Y placas revisadas.
   - El operador decide si genera o no.
   - Si hay cambios posteriores al ultimo corte, se solicita GUARDAR PARCIAL de nuevo.
   - Un reporte PARCIAL NO limpia precarga, GPS temporal, SAP temporal ni avance; permite continuar.
   - Un reporte COMPLETO conserva el cierre/limpieza productivo existente.

3. TERMINAR SEGUIMIENTO
   - Sigue siendo el cierre completo y requiere todas las placas revisadas.
   - Las marcas REVISADA sin cambios ya NO se cuentan falsamente como OCs editadas.

4. VER HORAS
   - Se mueve dentro del mapa, esquina superior derecha, como en escritorio.

5. SECUENCIA GPS COMPACTA
   - INGRESO/SALIDA se integra en el nombre: INGRESO CALCESUR / SALIDA CALCESUR.
   - Se elimina la linea separada de tipo de evento para ahorrar espacio.

MIGRACION REQUERIDA
-------------------
Esta version SI incluye una migracion nueva:
  supabase/migrations/20260912_version3_guardado_parcial.sql

La migracion:
- habilita estados PARCIAL/COMPLETO en cemento_reporte_control;
- guarda placas_revisadas;
- crea cemento_seguimiento_cortes;
- corrige cemento_consolidar_seguimiento para no contar REVISADA como edicion.

DESPLIEGUE
----------
1) Aplicar migracion.
2) Desplegar cemento-seguimiento y cemento-reporte.
3) Desplegar Firebase Hosting.

PRUEBA RECOMENDADA
------------------
A. Revisar 3 de varias placas y pulsar GUARDAR PARCIAL.
B. Confirmar fecha/hora y 3/N en el mensaje.
C. Ir a Crear Reporte: debe estar habilitado y advertir 3/N antes de descargar.
D. Generar reporte parcial: NO debe borrar la precarga ni el avance.
E. Volver a Seguimiento: las 3 placas deben continuar REVISADA.
F. Hacer un cambio nuevo despues del corte: reporte debe pedir un nuevo GUARDAR PARCIAL.
G. Completar todas y TERMINAR SEGUIMIENTO: reporte completo sin advertencia parcial.
