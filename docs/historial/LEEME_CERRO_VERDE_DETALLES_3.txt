CERRO VERDE WEB - DETALLES 3
============================

Parche acumulativo y exclusivo para Cerro Verde.
No contiene archivos de Cemento, del Editor de Geocercas ni de la portada.

CORRECCIONES
1. GUARDAR FECHA
   - Usa un input de fecha y hora igual al de Cemento.
   - Convierte el valor a DD/MM/AAAA HH:MM:SS antes de enviarlo.
   - Registra el corte mediante la función existente de Cerro Verde.
   - Vuelve a consultar Supabase y muestra la fecha realmente confirmada.
   - Sólo después de confirmarla actualiza el corte temporal del navegador.
   - Precarga y Seguimiento leen ese mismo valor confirmado.
   - Si falla, muestra el error y conserva el corte anterior.

2. ACTUALIZAR SAP
   - Estructura visual alineada con Cemento.
   - Panel de flujo operativo, título, explicación y archivo temporal.
   - Botones separados y legibles: SELECCIONAR EXCEL, VALIDAR ARCHIVO y APLICAR CAMBIOS.
   - Estados visibles: VALIDANDO, APLICANDO, error y aplicación completa.
   - Mantiene compatibilidad con archivos SAP .xls y .xlsx.
   - El archivo completo continúa almacenándose únicamente en el navegador.

3. CONSERVA DETALLES 2
   - Precarga visible y en segundo plano.
   - Dos intentos máximos por unidad.
   - Seguimiento en tres columnas.
   - Unidad sin movimiento con marcador U, última fecha y hora.

APLICAR EN CLOUD SHELL
----------------------
cd ~/PLATAFORMA_ITINERARIOS_WEB_BASE_COMPLETA_CV_DETALLES_1
unzip -o ~/CERRO_VERDE_WEB_DETALLES_3.zip
firebase deploy --only hosting --project itinerarios-2fa6f

No requiere desplegar funciones de Supabase: utiliza las funciones Cerro Verde existentes.
No ejecute Firebase deploy desde la carpeta aislada del parche.

PRUEBA DE FECHA
---------------
1. Ingrese una fecha y hora y presione GUARDAR FECHA.
2. Espere el mensaje FECHA GUARDADA con el valor confirmado.
3. Recargue la página y compruebe que la fecha se mantiene.
4. Abra Precargar rutas y confirme que DESDE coincide con el corte guardado.
5. Abra Seguimiento y confirme el mismo inicio de rango.
