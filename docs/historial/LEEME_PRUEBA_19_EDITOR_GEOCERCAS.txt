PLATAFORMA ITINERARIOS · PRUEBA 19 · EDITOR MAESTRO DE GEOCERCAS
=================================================================

BASE Y ALCANCE
--------------
Esta versión conserva íntegramente CEMENTO (Prueba 17.1) y CERRO VERDE
(Prueba 18). Añade una tercera herramienta independiente en la lista general:
EDITOR DE GEOCERCAS.

El editor administra por separado la cartografía de CEMENTO y CERRO VERDE.
Copiar una geocerca entre itinerarios crea una copia independiente en el
borrador destino; el nombre y la geometría pueden modificarse sin afectar al
itinerario de origen.

FUNCIONALIDAD DEL EDITOR
------------------------
- Ramas independientes: GEOCERCAS, RUTAS MADRE y TRAMOS.
- Objetos inicialmente ocultos; control individual con ojo y VER TODOS.
- Centrar, renombrar, eliminar y editar vértices directamente en Google Maps.
- Crear polígonos para geocercas/tramos y líneas para rutas madre.
- Copiar un objeto a otro itinerario, pudiendo asignarle otro nombre.
- Importar juntos los tres archivos canónicos:
  GEOCERCAS.json, RUTAS_MADRE.json y GEOCERCA_TRAMO.json.
- Flujo controlado: GUARDAR BORRADOR -> VALIDAR -> SUBIR AL ITINERARIO.
- Sólo ADMIN puede publicar. EDITOR puede preparar y validar los itinerarios
  que tenga autorizados.
- Publicación por reemplazo total, nunca por mezcla incremental.
- Antes de reemplazar una publicación se guarda automáticamente la versión
  anterior en el historial de respaldos.
- Permanencia operativa general: 20 minutos.
- Puertas y accesos se ignoran y no forman parte del maestro publicado.

INTEGRACIÓN OPERATIVA
---------------------
Después de publicar, cemento-clocator y cerro-verde-clocator consultan la
geocerca vigente de SU PROPIO itinerario. Si todavía no existe publicación o
la consulta falla, conservan como respaldo la cartografía incluida en el
código actual. El editor no modifica Seguimiento, Histórico ni reportes.

RUTAS_MADRE.json y GEOCERCA_TRAMO.json también quedan publicados en el mismo
paquete independiente del itinerario, listos para el uso cartográfico de esa
operación. No se comparten automáticamente entre CEMENTO y CERRO VERDE.

DESPLIEGUE INCREMENTAL DESDE CLOUD SHELL
----------------------------------------
1. Descomprimir y entrar a la carpeta:
   cd ~
   unzip -o PLATAFORMA_ITINERARIOS_WEB_PRUEBA_19_EDITOR_GEOCERCAS.zip
   cd PLATAFORMA_ITINERARIOS_WEB_PRUEBA_19_EDITOR_GEOCERCAS

2. En Supabase SQL Editor abrir:
   supabase/migrations/20260911235757_editor_geocercas_web.sql
   Copiar y ejecutar EL CONTENIDO del archivo. No pegar la ruta como SQL.

3. Autenticar Supabase si fuera necesario:
   npx supabase@latest login

4. Desplegar la nueva función y los dos conectores actualizados:
   for f in editor-geocercas cemento-clocator cerro-verde-clocator; do
     npx supabase@latest functions deploy "$f" --project-ref otvdwqbrqvxahyzfkhds --no-verify-jwt || exit 1
   done

5. Desplegar Firebase Hosting:
   firebase deploy --only hosting --project itinerarios-2fa6f

6. Abrir:
   https://itinerarios-2fa6f.web.app
   Iniciar sesión y seleccionar EDITOR DE GEOCERCAS.

PRIMERA PUBLICACIÓN CONTROLADA
-----------------------------
1. Elegir CEMENTO o CERRO VERDE.
2. IMPORTAR 3 JSON y seleccionar juntos los tres archivos canónicos.
3. Revisar cada rama y mostrar sólo los objetos necesarios.
4. GUARDAR BORRADOR.
5. VALIDAR.
6. SUBIR AL ITINERARIO y confirmar el reemplazo total.
7. Abrir el seguimiento del mismo itinerario y probar una ruta conocida.
8. Repetir para el otro itinerario con su propio conjunto cartográfico.

SEGURIDAD Y ALMACENAMIENTO
--------------------------
- El navegador nunca recibe SUPABASE_SERVICE_ROLE_KEY.
- La Edge Function verifica el JWT de Firebase y los permisos de app_usuarios.
- Las tablas del editor tienen RLS, sin permisos para anon/authenticated; sólo
  son accesibles desde la función mediante service_role.
- La llave de Google Maps se entrega únicamente a usuarios autorizados.
- No se guardan puntos GPS en estas tablas.
- Cada conjunto se limita a 8 MB para evitar cargas accidentales excesivas.

VALIDACIONES TÉCNICAS REALIZADAS
--------------------------------
- Sintaxis JavaScript del editor y de la plataforma validada.
- Bundle TypeScript válido para editor-geocercas, cemento-clocator y
  cerro-verde-clocator.
- Validación server-side de tipos, coordenadas, IDs duplicados y tamaño.
- Enlaces HTML y archivos estáticos verificados.
- No se incluyen ejecutables: el despliegue se realiza en Cloud Shell y toda
  la operación se usa mediante la URL web.
