CORRECCIÓN ACUMULADA · PRUEBA 16 CEMENTO
========================================

Se incorporó el maestro recibido sin crear tablas ni filas nuevas en Supabase:

- Placa Tracto -> GESTOR.
- Orden de Carga -> SAP histórico -> LicencCond -> Celular.
- Varios teléfonos válidos se muestran juntos, sin repetir, separados por " / ".

- Si una licencia no tiene teléfono maestro, se conserva el teléfono existente del seguimiento
  o el teléfono SAP cuando esté informado.

Esta relación se aplica al crear el Excel final y también al descargar SEGUIMIENTO_DIARIO o
SEGUIMIENTO_HISTORICO. No altera las OCs guardadas ni duplica estos datos por cada registro.
