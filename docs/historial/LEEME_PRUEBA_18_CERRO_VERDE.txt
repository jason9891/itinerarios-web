========================================================

BASE
----
Se construyó exclusivamente sobre CEMENTO_WEB_FIREBASE_PRUEBA_17_1.
El funcionamiento CEMENTO y sus funciones originales no fueron sustituidos.

NUEVO
-----
- Pantalla inicial escalable con la lista general de itinerarios.
- Cemento y Cerro Verde se abren de forma independiente; Quellaveco queda reservado como próxima integración.
- Dentro de cada operación existe VOLVER A ITINERARIOS; no se navega directamente de una operación a otra.
- Autenticación Firebase compartida y autorización independiente por itinerario.
- Tablas Supabase compartidas usando ITINERARIO = CERRO VERDE.
- SAP temporal en IndexedDB y GPS temporal separado de Cemento.
- Precarga con máximo dos intentos, sin bucle infinito.
- Seguimiento por Entrega SAP y placa con los eventos:
  SALIDA BASE, LLEGADA CARACOTO, INGRESO/SALIDA CARGUÍO,
  SALIDA CARACOTO, LLEGADA/SALIDA RACIEMSA CARGADO,
  INGRESO/SALIDA SMCV y LLEGADA RACIEMSA VACÍO.
- GPS propone y el operador confirma. Convoy deshabilitado.
- Pernoctes y pausas activas separados de Cemento.
- Descarga bajo demanda de Diario e Histórico.
- Reporte Cerro Verde con hojas CAL VACIO, CAL CARGADO y PERNOCTES.
- Consumo de BD, Storage y Egress continúa identificado por itinerario.

DESPLIEGUE DESDE CLOUD SHELL
---------------------------
1. Descomprimir y entrar a la carpeta:
   cd ~
   unzip -o PLATAFORMA_ITINERARIOS_WEB_PRUEBA_18_CERRO_VERDE.zip
   cd PLATAFORMA_ITINERARIOS_WEB_PRUEBA_18_CERRO_VERDE

2. En Supabase SQL Editor, abrir:
   supabase/migrations/20260912_prueba18_cerro_verde.sql
   Copiar y ejecutar SU CONTENIDO. No escribir la ruta del archivo como SQL.

3. En Cloud Shell autenticar Supabase si fuera necesario:
   npx supabase@latest login

4. Desplegar funciones nuevas (desde esta carpeta):
   for f in cerro-verde-consulta cerro-verde-clocator cerro-verde-seguimiento cerro-verde-sap cerro-verde-reporte; do
     npx supabase@latest functions deploy "$f" --project-ref otvdwqbrqvxahyzfkhds --no-verify-jwt || exit 1
   done

5. Desplegar Firebase Hosting:
   firebase deploy --only hosting --project itinerarios-2fa6f

6. Abrir:
   https://itinerarios-2fa6f.web.app
   Iniciar sesión en la ventana general y seleccionar CEMENTO o CERRO VERDE.

CONTROL ANTES DE OPERAR
-----------------------
- La cuenta debe estar ACTIVA y su arreglo ITINERARIOS incluir CERRO VERDE.
- La migración añade CERRO VERDE automáticamente sólo a cuentas ADMIN.
- Verificar secretos existentes: CLOCATOR_* y GOOGLE_MAPS_API_KEY.
- Cargar/validar SAP Cerro Verde antes de crear el primer Diario.
- No borrar ni desplegar sobre las funciones cemento-*.

VALIDACIONES TÉCNICAS REALIZADAS
--------------------------------
- app.js y cerro-verde.js: sintaxis JavaScript válida.
- Cinco Edge Functions Cerro Verde: parseo/bundle TypeScript válido.
- GEOCERCAS.json: JSON válido; Cerro Verde filtra CALCESUR, RACIEMSA y SAN JOSE SMCV.
- No se incluyen ejecutables: todo se despliega desde Cloud Shell y se usa por URL.
