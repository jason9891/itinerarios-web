CONTRASEÑA
----------
El acceso Email/Password de Firebase usa una contraseña de Firebase, no la contraseña del buzón Gmail.
El flujo de “olvidé mi contraseña” sí requiere acceso al correo. En cambio, un administrador de Firebase puede establecer una nueva contraseña mediante Firebase Admin SDK sin acceso al buzón. Esa función administrativa NO se incluye todavía en este paquete para no introducir credenciales de servicio dentro del frontend.
