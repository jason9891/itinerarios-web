REGLA IMPLEMENTADA
------------------
Una fila repetida se identifica por:
  OC + FECHA SAP + CONDUCTOR + PLACA TRACTO + PLACA CARRETA

1. Todo coincide:
   Es la misma OC de un SAP anterior. No se vuelve a mostrar.

2. La OC coincide, pero cambia fecha, conductor o alguna placa:
   Es una OC reasignada.

3. OC reasignada cerrada sin horas operativas:
   - vuelve limpia a DIARIO;
   - usa los nuevos datos SAP;
   - avisa: OC XXXXX VACÍA REASIGNADA.

4. OC reasignada cerrada con alguna hora operativa:
   - vuelve a DIARIO;
   - conserva las horas anteriores;
   - actualiza asignación, conductor, unidad y ruta desde SAP;
   - avisa: OC XXXXX YA EXISTE CON INFORMACIÓN; SE REABRE PARA VALIDACIÓN.

5. OC que sigue abierta:
   No se duplica ni se reemplaza automáticamente.

Se consideran horas operativas:
- FECHA DE SALIDA PLANTA YURA/CARACOTO
- FECHA LLEGADA A DESTINO
- FECHA INICIO DE RETORNO
- FECHA FIN DE RETORNO AQP/YURA/CRCT

VALIDACIÓN OPERATIVA
--------------------
1. Cargar un SAP que contenga OCs del día anterior sin cambios.
   Deben aparecer como cerradas sin cambios o ya abiertas; no se aplican otra vez.

2. Cargar una OC cerrada cuyo conductor, fecha o placas hayan cambiado.
   Debe aparecer como VACÍA REASIGNADA o CON INFORMACIÓN.

3. Aplicar el SAP y abrir Seguimiento.
   La OC reasignada debe volver a DIARIO y aparecer una sola vez.

4. Confirmar que CEMENTO conserva Guardar parcial, reporte ZIP y placas revisadas.

5. Confirmar que Cerro Verde abre normalmente. Este paquete no lo modifica.
