PLATAFORMA ITINERARIOS WEB — DETALLES_1
Fecha: 12/09/2026
Base técnica: PRUEBA 19.3, sin continuar la numeración de pruebas.

OBJETIVO DE ESTA ENTREGA
========================
Corregir el bloque de cartografía/rutas detectado en la revisión de ITINERARIOS WEB.

CAMBIOS PRINCIPALES
===================
1. RUTAS MADRE YA NO SON "SOLO EDITOR".
   - Se pueden asignar por itinerario.
   - Se publican junto con GEOCERCAS y GEOCERCAS DE RUTA.
   - CEMENTO queda preparado con 44 rutas madre asignadas.

2. CARTOGRAFÍA CEMENTO RECUPERADA DESDE LA FUENTE VALIDADA.
   - 18 geocercas operativas asignadas a CEMENTO.
   - 44 rutas madre visibles/asignables/publicables.
   - 43 rutas cuentan con cobertura productiva validada para análisis.
   - La ruta manual adicional se conserva, pero NO se inventa cobertura para ella.
   - 1 TRAMO_TRANSITO validado: TRAMO MOQUEGUA - PEAJE MONTALVO.

3. ANÁLISIS DE UBICACIÓN EN RED.
   Prioridad implementada:
   AREA_OPERATIVA confirmada (permanencia >= 20 min)
       -> TRAMO_TRANSITO_VALIDADO
       -> COBERTURA_RUTA_MADRE (desempate por distancia a la línea madre)
       -> FUERA DE RED VALIDADA · REVISAR

   TRAMO_TRANSITO no genera ingreso, salida ni permanencia.
   No se crean buffers ni geometrías nuevas.

4. NOMBRES OPERATIVOS.
   - Se elimina el sufijo final "COPIA" de las asignaciones recuperadas.
   - El ID maestro se conserva.

5. BOTÓN VERDE / PUBLICACIÓN.
   - Cursor real de botón y hover visible.
   - Antes de publicar muestra conteos de:
       geocercas / rutas madre / geocercas de ruta.
   - Después de publicar muestra confirmación explícita:
       "RUTAS Y GEOCERCAS ACTUALIZADAS EN EL ITINERARIO CEMENTO"
   - En CEMENTO invalida la precarga GPS local para forzar el recálculo.

6. SEGUIMIENTO CEMENTO.
   - Muestra UBICACIÓN EN RED.
   - Muestra FUENTE DEL ANÁLISIS.
   - Cuando hay solape de coberturas, muestra rutas candidatas y distancia.
   - En el mapa se dibujan las rutas madre publicadas como referencia.

7. MIGRACIÓN SEGURA DE 19.3 A DETALLES_1.
   - No requiere SQL nuevo.
   - El backend reconoce un Maestro anterior y prepara automáticamente los datos faltantes.
   - NO escribe silenciosamente: la interfaz pedirá GUARDAR MAESTRO y luego VALIDAR.

DESPLIEGUE EN CLOUD SHELL
=========================
Subir el ZIP a Cloud Shell y ejecutar:

cd ~
unzip -o PLATAFORMA_ITINERARIOS_WEB_DETALLES_1.zip
cd ~/PLATAFORMA_ITINERARIOS_WEB_DETALLES_1

npx supabase@latest functions deploy editor-geocercas \
  --project-ref otvdwqbrqvxahyzfkhds \
  --no-verify-jwt

npx supabase@latest functions deploy cemento-clocator \
  --project-ref otvdwqbrqvxahyzfkhds \
  --no-verify-jwt

firebase deploy --only hosting

PRIMERA VALIDACIÓN DESPUÉS DEL DEPLOY
=====================================
1. Entrar a EDITOR DE GEOCERCAS.
2. Si aparece el aviso DETALLES_1 preparado, pulsar GUARDAR MAESTRO.
3. Pulsar VALIDAR.
4. Elegir ASIGNACIONES · CEMENTO.
5. Revisar las tres pestañas:
   - GEOCERCAS
   - RUTAS MADRE
   - GEOCERCAS DE RUTA
6. Pulsar SUBIR A CEMENTO.
7. Debe aparecer una confirmación con:
   18 geocercas · 44 rutas madre · 1 geocerca de ruta
   y el texto de actualización del itinerario.
8. Abrir Seguimiento CEMENTO y ejecutar/rehacer la precarga.
9. Revisar UBICACIÓN EN RED y FUENTE DEL ANÁLISIS en el panel derecho.

REGLAS QUE NO SE CAMBIARON
==========================
- Permanencia mínima de geocerca: 20 minutos.
- Puertas/accesos GPS no se usan.
- No se inventan horarios fuera del rango GPS disponible.
- No se recalculan ni alteran hitos operativos por la clasificación de ruta.
- TRAMO_TRANSITO es ubicación física, no un nuevo estado operativo.
